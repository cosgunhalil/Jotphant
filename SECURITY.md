# Security Policy

Jotphant is a local desktop application. It makes no network connections and
stores all data on your own machine, so its attack surface is small. We still
take any report seriously.

## Supported versions

Only the latest release receives security fixes. Please update to the newest
version from the Releases page before reporting.

## Reporting a vulnerability

Please do not open a public issue for security problems.

1. Preferred: use GitHub's private vulnerability reporting. Open the Security
   tab of this repository and choose "Report a vulnerability". The report stays
   private between you and the maintainer until a fix is released.
2. Fallback: email cosgun.halil@gmail.com with the details.

Include what you found, steps to reproduce it, and the version you tested.

## What to expect

You will get a first response within a few days. If the report is confirmed,
a fix ships in the next release and you will be credited in the release notes
unless you prefer otherwise.
